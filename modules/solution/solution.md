# 3-1. 솔루션 제안 (`solution`)

매체 외에 실행할 수 있는 솔루션 제안

| 파일 | 내용 |
|---|---|
| `solution_main.html` | 화면 (`<section id="solution-section">` 하나) |
| `solution_style.css` | 디자인 (class는 `solution-`로 시작) |
| `solution_script.js` | 화면 기능 (`Solution` 객체, `Solution.init()`) |
| `solution_server.py` | 서버 기능 (주소는 `/solution/...`) |
| `images/` | solution에서만 쓰는 이미지 |
| `data/` | solution에서만 쓰는 데이터 |
