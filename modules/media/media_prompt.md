## AI에게: 기록 규칙

이 파일을 읽은 AI는 `modules/media/` 작업이 끝날 때마다 아래 규칙대로 기록해 주세요.

**기록하는 것**
- 결과가 잘 나와서 담당자가 받아들인 프롬프트
- 처음엔 실패했지만 프롬프트를 고쳐서 해결한 경우 (실패한 프롬프트와 고친 프롬프트 모두)
- AI가 틀린 정보를 지어내거나(환각), 시키지 않은 파일을 고치는 등 실수를 막은 프롬프트
- 앱 안에서 쓰는 AI 프롬프트(시스템 프롬프트 등)를 새로 만들거나 고친 경우

**기록하지 않는 것**
- "안녕", "응", "맞아", "고마워", "ㅇㅋ", "다시 해 줘", "계속" 같은 짧은 말
- 오타 수정, 파일 위치 묻기처럼 결과가 남지 않는 단순 요청
- 이미 기록한 것과 거의 같은 프롬프트

**쓰는 방법**
- 프롬프트는 담당자가 쓴 **원문 그대로** 넣습니다. 다듬거나 요약하지 않습니다.
- API 키, 비밀번호, Supabase 주소, 개인정보는 `***`로 가립니다.
- 새 기록은 `## 기록` 맨 아래에 번호를 이어서(P-01, P-02 …) 추가합니다. 이전 기록은 고치거나 지우지 않습니다.
- 기록을 추가했다면 `## 요약`의 표도 한 줄 갱신합니다.
- 앱 안 AI 프롬프트를 고쳤다면 `## 앱 안 AI 프롬프트 버전`에도 한 줄 추가합니다.
- 기록했다면 작업 끝에 "프롬프트 기록에 P-00을 추가했습니다"라고 알려 줍니다.

**결과**: media_ab.py(A/B 안, 규칙, 촬영 브리프 다운로드, AI 각도 레퍼런스 프롬프트, Manage Your Experiments 안내, 가상 결과·판정·CAC), data/media_ab_result_dummy_202610.json, media_page.py에서 호출
**다음에 쓸 팁**: 플랫폼 규칙(아마존 메인 이미지 등)이 있는 소재는 "규칙 안에서 바꿀 수 있는 변수만 A/B로" 요청하면 쓸 수 없는 안이 나오지 않는다

### P-02 · 2026-10-24 · A/B 단일 변수 선정 섹션 추가

- 분류: 기능 구현
- 문제 유형: 없음

**잘 쓴 프롬프트 (원문)**
```text
아니 나 미디어 담당자라서 지금 3번 탭 진행할거야. 2번 탭에서 받아올 가설을 [ 만약 메인 이미지를 펼친 패드의 냉감 원단 질감과 두께가 보이는 각도로 바꾸면, 저가 제품과의 품질 차이가 바로 보여서, 'kühlende matratzenauflage' 검색에서 클릭 점유율 ÷ 노출 점유율이 0.63배에서 0.8배 이상으로 오를 것이다.] 라고 고정할게. 

그럼 위 가설을 기반으로 A/B 테스트를 진행할 때 단일 변수 선정하는 것 까지만 먼저 해보자.
```

**처음 시도와 문제**
- 처음 프롬프트: "그런데 3번 탭에서 가설에 따른 단일 변수를 하나 뽑아서 A/B 테스트를 진행하는데 집중해야 하는데 지금 가설이 너무 모호한 것 같아. 어떻게 이 상황을 해결할 수 있을까? 어디가 문제야?"
