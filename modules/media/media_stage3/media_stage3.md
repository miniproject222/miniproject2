# 3. 매체 제작 > 3단계: 사진·영상 초안 → 외주 정리 (`media_stage3`)

- 담당 브랜치: `DH`
- 3번 탭(`media`)의 하위 탭 **④ 사진·영상 초안 제작**과 **⑤ 외주 정리**를 만듭니다. (탭 이름은 아래 "하위 탭 이름" 참고)
- 2단계가 AI로 다듬어 넘긴 프롬프트 A·B를 받아 **사진 레퍼런스 → 영상 스토리보드 → 영상 초안**을 만들고,
  **외주 촬영 업체 또는 사내 촬영팀에 보낼 자료를 zip 하나로** 묶습니다. 사진 초안은 프롬프트 A·B로, 영상 초안은 스토리보드로 만든 영상 프롬프트로 만듭니다.
- 개발이 끝나면 1단계(`min` 브랜치) 기준으로 합칩니다.

## 전체 흐름에서 3단계 위치

| 하위 탭 | 담당 | 하는 일 |
|---|---|---|
| ① 가설에서 변수 도출 · ② A/B 소재 준비 | min | 가설에서 단일 변수 추출 → A,B 테스트 소재 선정 |
| ③ 프롬프트 만들기 | JY | 기본 프롬프트 → 빈칸 → A, B 채우기 → **리포트 값으로 AI 다듬기 + 확인** |
| **④ 사진·영상 초안 제작** | **DH** | **프롬프트 A·B로 사진 초안, 스토리보드 → 영상 프롬프트로 영상 초안** |
| **⑤ 외주 정리** | **DH** | **촬영 브리프 + 찍지 말 것/넣을 것 + 만든 자료를 zip으로** |

## 작업 범위

- **이 폴더(`modules/media/media_stage3/`) 안에서만** 작업합니다.
- `modules/media/` 바로 아래 파일(`media_page.py`, `media_handoff.py`, `media_style.css`, 문서 등)과 `media_stage2/`는 고치지 않습니다.
  바꿔야 하면 1단계 담당자에게 무엇을 왜 바꿔야 하는지 알립니다.

| 파일 | 내용 |
|---|---|
| `media_stage3.py` | 하위 탭 ④ 사진·영상 초안 제작. 진입 함수 `media_stage3_render()` (이름은 바꾸지 않음) |
| `media_stage3_ai.py` | ④의 AI 호출: 사진 초안 `media_s3_make_image()`·스토리보드 `media_s3_make_storyboard()`(OpenAI), 영상 초안 `media_s3_make_video()`(Higgsfield Seedance 2.5). 모델·화질·영상 길이는 파일 맨 위 상수 |
| `media_stage3_hf_login.py` | Higgsfield 계정 로그인 (컴퓨터마다 처음 한 번). ④ 영상 초안 제작의 **'Higgsfield 로그인 창 열기'** 버튼을 누르면 시크릿 창(크롬 `--incognito`, 엣지 `--inprivate`, 없으면 기본 브라우저)으로 로그인 화면이 뜨고, 로그인하면 앱이 3초 안에 알아챔. '계정 바꾸기'로 로그인 지우기. 앱을 **자기 컴퓨터에서 켰을 때만** 동작(돌아오는 주소가 127.0.0.1:8765). 터미널로도 가능: `python -m modules.media.media_stage3.media_stage3_hf_login`. 로그인 열쇠를 `.streamlit/hf_mcp_token.json`에 저장 (`.gitignore`에 등록됨) |
| `media_stage3_hf_mcp.py` | Higgsfield MCP(`https://mcp.higgsfield.ai/mcp`)로 영상 만들기: `generate_video` → `jobs_wait`. 구독 크레딧 사용, 열쇠 자동 갱신 |
| `media_stage3_store.py` | 작업물 보관: 만든 결과 기록(`history/`, `history.json`)·고른 목록·만드는 중인 영상 작업 번호를 `data/workspace/`에 저장하고 화면을 그릴 때 다시 읽음. **사진·영상 초안 제작 탭의 작업물(사진·영상·스토리보드·확정본)은 이번 접속 동안만**(`MEDIA_S3_SESSION_ONLY`, 폴더에 쓰지도 읽지도 않음) |
| `media_stage3_export.py` | 하위 탭 ⑤ 외주 정리. 진입 함수 `media_stage3_export_render()` (이름은 바꾸지 않음) |
| `media_stage3_pdf.py` | ⑤ 외주 촬영 브리프 PDF(보고서 형식, `media_s3_build_pdf()`): 이번 촬영의 목적(가설·단일 변수·A안·B안) → 촬영 지시(찍지 말 것·넣을 것) → 참고 프롬프트 A·B → 영상 스토리보드 표 → 함께 보내는 파일. 공통 폰트 SUIT(`common/fonts`, 읽기만), 움라우트 등은 바꿔 씀 |
| `media_stage3_style.css` | 디자인 (class는 `media-s3-`로 시작). `media_page.py`가 3번 탭을 열 때 읽어 넣습니다 |
| `media_stage3_prompt.md` | 프롬프트 기록 |
| `data/` | 3단계에서만 쓰는 데이터 |
| `images/` | 3단계에서만 쓰는 이미지 |

## 하위 탭 이름

- ④ 이름은 `media_stage3.py`의 `MEDIA_S3_TAB_LABEL`(지금 '사진·영상 초안 제작'), ⑤ 이름은 `media_stage3_export.py`의 `MEDIA_S3_EXPORT_TAB_LABEL`(지금 '외주 정리')에서 정합니다. 바꾸면 하위 탭과 이전/다음 버튼 글자가 함께 바뀝니다.
- 폴더·파일·함수·key 이름은 탭 이름이 아니라 단계 번호(`media_stage3`, `media_s3_`, `media-s3-`)라서 탭 이름이 바뀌어도 그대로 둡니다.
- 화면 안에 탭 이름을 문자열로 다시 쓰지 않습니다. 필요하면 위 상수를 씁니다.

## 이름 규칙 (같은 media 안에서 겹치지 않게)

- 함수: `media_s3_...` (진입 함수만 `media_stage3_render`, `media_stage3_export_render`)
- 위젯 `key`, `st.session_state` 키, CSS class: `media-s3-...` (예: `key="media-s3-btn-export"`)
- Supabase 표를 만들면 `media_` 로 시작 (예: `media_reference`)

## 받는 값 (2단계 → 3단계)

`media_handoff_prompt()`(`modules/media/media_handoff.py`)로 받습니다. 2단계가 아직 넘기지 않았으면 예시 값(`MEDIA_HANDOFF_PROMPT_SAMPLE`)에 `sample: True`가 붙어 옵니다.

| 키 | 내용 |
|---|---|
| `variable` | 단일 변수 이름 |
| `base`, `slot_a`, `slot_b` | 기본 프롬프트(빈칸 `{slot}`)와 A·B 빈칸 문구 |
| `fixed` | 고정 요소 (다듬은 뒤에도 그대로 있어야 하는 문구) |
| `prompt_a`, `prompt_b` | **2단계에서 다듬은 프롬프트 A·B** (비어 있으면 빈칸만 채운 문장) |
| `changes` | 바꾼 곳 표 (바꾼 곳 / 뺌·더함 / 이유 / 근거 DB ID) |
| `avoid`, `include` | **찍지 말 것 / 넣을 것** → ⑤ 촬영 브리프에 그대로 들어감 |

- 받은 A·B는 `media_handoff_check()`로 한 번 더 확인합니다 (빈칸만 다른가, 고정 요소가 남았나).
- 리포트 값(`store_get("report")`)은 ④ 스토리보드에서 `ad_claims.allowed_scenes`(허용 장면)를 씁니다.

## 화면 구성

### ④ 사진·영상 초안 제작 (`media_stage3.py`, AI는 `media_stage3_ai.py`)
- AI 버튼은 `.streamlit/secrets.toml`에 키가 있으면 켜지고 (사진·스토리보드는 `OPENAI_API_KEY`, 영상은 `HF_KEY` = "키ID:키시크릿"), 없으면 꺼진 채 "키를 넣어 주세요" 안내가 보입니다. 키가 없어도 파일을 직접 올려서 끝까지 진행할 수 있습니다.
- 화면 맨 위에서 받은 프롬프트 A·B를 확인하고, 안쪽 하위 탭 3개(`st.tabs(key="media-s3-sub")`: 사진 초안 제작 / 영상 초안 제작 / 만든 결과 보기)로 나눕니다.
- **가설 묶음** (`media_s3_group()`): 2단계 프롬프트 A·B가 같으면 같은 묶음. 사진·영상을 넣을 때 그 묶음(가설 문장·단일 변수·A·B)을 함께 기록합니다. 작업 공간, '방금 만든 영상', ⑤로 넘기는 값은 **지금 가설 묶음 것만** 보여 줘서, 가설이 바뀌면 작업 공간이 비고 예전 결과가 섞이지 않습니다.
- **사진 초안 제작** (`media_s3_photo_section()`): **사진 A·B 프롬프트 칸이 메인**(화면 폭 전체, 남는 높이만큼 프롬프트 칸이 커지고 A·B 항상 같은 크기). 브라우저 100%에서 화면 전체를 빈 곳 없이, 스크롤 없이 씀 (1910×915, 1680×860, 1468×718, 1366×657에서 확인). 이 탭을 연 동안만 ③ 탭의 최대 폭(`media_style.css`의 1400px)을 풀고, 높이는 CSS 변수 `--media-s3-h`(= 화면 높이 - 382px, 최소 270px)로 맞춤. 칸마다 '사진 A' · '프롬프트 보기'(팝업) · '사진 A 만들기', 프롬프트 전체, 높은 화면에서는 'A만 다른 점'. 아래 한 줄에 **'만든 사진 보기 (n)'** · '📁 직접 만든 사진 올리기' · ⑤로 넘기기. **만든 사진은 팝업 창**(`media_s3_photo_dialog()`): 사진을 만들거나 올리면 바로 뜨고, A가 있으면 A부터(→로 B), 없으면 방금 만든 사진부터(`_media_s3_photo_open_first()`). 팝업 안은 넘겨 보기(`media_s3_photo_carousel()`: 3:2 사진, ← →, 사진 A / 사진 B / 올림 n 고르기, 내려받기·지우기 아이콘). 오른쪽 위 X나 Esc로 닫고, '만든 사진 보기'로 언제든 다시 엶. 순서는 AI 사진 A, B 먼저 그다음 올린 사진(`media_s3_photo_list()`), 지금 보는 번호는 `media-s3-photo-idx`. ④ 맨 위 알림(2단계 예시 프롬프트, A·B 차이 경고)은 각 탭 아래 안내 줄 앞에 주황색으로 붙임(`media_s3_notice()`). ⑤로 넘기기 줄은 하위 탭마다 하나씩(key: 사진 `media-s3-btn-handoff`, 영상 `-video`, 결과 보기 `-history`)
- **영상 초안 제작** (`media_s3_video_tab()`): 사진 초안 제작과 같은 배치·크기, 100% 화면에서 스크롤 없이 한 화면 (4가지 크기 확인). 왼쪽(남는 폭 전부): **① 스토리보드 카드**(제목 줄에 배지 '확정됨 / 다시 확정 필요 / 금지 표현 있음'과 '스토리보드 만들기'·'스토리보드 확정' 버튼, 허용 장면·금지 표현 설명은 제목 ⓘ, 표 높이는 화면 높이를 따라감), 한 줄에 '📁 직접 만든 영상 올리기' · ⑤로 넘기기, 한 줄 안내(아주 낮은 화면에서는 숨김). 오른쪽: 사진 넘겨 보기와 같은 크기의 **② 영상 초안 만들기 카드**(Higgsfield 로그인 상태 한 줄, 영상 프롬프트 칸 안 스크롤, '영상 초안 만들기', 만드는 중 상태). **'방금 만든 영상' 칸과 영상 작업 공간 목록은 없앰**: 만든 영상은 '만든 결과 보기'에서 봄
- **팝업 창 보기** (`st.dialog`): 사진 A·B의 **'프롬프트 보기'**(`media_s3_text_dialog()`, 'A만 다른 점' 함께), 스토리보드 제목 줄의 **'크게 보기'**(`media_s3_storyboard_dialog()`, 표 전체·고치기는 화면의 표에서), 영상 카드 제목 줄의 **'프롬프트 보기'**(영상 프롬프트 전체). 버튼 key는 `media-s3-btn-view-A/B/sb/video/photos`, 흰 바탕 + 진한 글자. 팝업 글자를 가리지 않게 보기 버튼과 ← →에는 마우스 설명(help)을 달지 않음. 사진 A·B 칸은 왼쪽 칸의 남는 높이를 모두 채우고 늘어난 만큼 프롬프트 칸이 커짐 (A·B 항상 같은 크기)
- **만든 결과 보기** (`media_s3_history_section()`): 100% 화면에서 스크롤 없이 한 화면 (4가지 크기 확인, 이 탭도 최대 폭을 풂). **왼쪽**: 최근 가설 5개 목록(라디오, 🟢 지금 가설, 사진·영상 수·보낸 수·최근 시각). 직접 고르기 전에는 지금 가설을 따라감. **오른쪽**: 맨 위 한 줄 '단일 변수 · A · B'(가설 전문은 ⓘ, 아주 낮은 화면에서는 숨김), 아래 **사진 A | 사진 B | 영상 (| 올린 사진)** 칸(`media_s3_history_slots()`, `media_s3_history_slot()`). 칸마다 한 장씩, 처음엔 최신 버전, 여러 장이면 제목 줄 ‹ › 와 `2/3`으로 버전을 넘김. 칸 아래 '⑤로 보내기' 체크와 내려받기·만든 프롬프트·**지우기**(그 버전의 기록과 사본을 지우고 보낼 목록에서도 뺌, `media_s3_store_history_remove()`). 사본은 `data/workspace/history/`, 목록은 `history.json`, 최근 가설 5개까지 왼쪽 목록 아래에 **고른 가설 전체 문장**, 오른쪽 맨 위는 '단일 변수 · A와 B는 이것만 달라요', **사진 A·B 위에는 'A만 다른 점 · …' 띠**(두 줄까지, 마우스를 올리면 전체).
- **사진 초안 제작**: 사진 A·B 칸마다 다듬은 프롬프트와 `사진 A 만들기`·`사진 B 만들기` 버튼
  - 누르면 그 프롬프트로 사진을 만들어(`gpt-image-1-mini`, 화질 low, 10~30초) 칸 안에 보여 주고 `photo_A_ai.png`·`photo_B_ai.png`로 보관 (다시 누르면 바꿔 끼움)
  - 직접 만든 사진도 올릴 수 있음 (AI 사진과 같이 보관)
- **영상 초안 제작**: 순서대로 진행
  1. **스토리보드 만들기**: `스토리보드 만들기` 버튼을 누르면 리포트 값(허용 장면 `ad_claims.allowed_scenes`, 쓸 수 있는 문구 `ad_claims.claims`, 금지 표현 `ad_claims.forbidden`, 서리 강점)과 프롬프트 A·B로 문제 → 해결 → 증거 → 신뢰 → 마무리 장면 표를 채움 (`gpt-4.1-mini`). 표는 직접 고칠 수 있고, 금지 표현이 남아 있으면 경고 → **`스토리보드 확정`**
  2. **영상 초안 만들기**: 스토리보드를 확정해야 열림. 확정한 장면을 이어 붙인 영상 프롬프트(`media_s3_video_prompt()`)로 `영상 초안 만들기`를 누르면 **Higgsfield 계정 로그인(MCP)이 되어 있으면 구독 크레딧으로**(Seedance 2.5, 5초 약 35크레딧), 아니면 **Higgsfield API 잔액(HF_KEY)으로** 영상을 만들어(`bytedance/seedance-2.5/text-to-video`, 5초, 720p, 16:9, 소리 없음, 1~5분) 화면에 보여 주고 `video_draft_ai.mp4`로 보관. **Higgsfield API는 선불 잔액에서 차감**(사이트 구독 크레딧과 별개, 최소 충전 $5). 잔액 부족·실패·검열이면 경고만 띄움. 직접 만든 영상도 올릴 수 있음
- 화면 맨 아래 **'⑤로 넘기기'** 버튼(`media_s3_handoff_step()`, 스토리보드를 확정해야 눌림)을 눌렀을 때만 확정한 스토리보드와 '만든 결과 보기'에서 고른 사진·영상의 기록 이름이 Supabase(`handoff.assets`)로 넘어갑니다. 넘기기 줄에 '보낼 것: 사진 n · 영상 m'이 보입니다. 넘긴 뒤 바뀌면 '다시 넘기기 필요'가 보입니다.
