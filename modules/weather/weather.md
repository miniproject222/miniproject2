# 4. 날씨 광고 타이밍 (`weather`)

날씨, 상황에 따른 광고(메타, 아마존) 노출 빈도와 예산 추천

| 파일 | 내용 |
|---|---|
| `weather_main.html` | 화면 (`<section id="weather-section">` 하나) |
| `weather_style.css` | 디자인 (class는 `weather-`로 시작) |
| `weather_script.js` | 화면 기능 (`Weather` 객체, `Weather.init()`) |
| `weather_server.py` | 서버 기능 (주소는 `/weather/...`) |
| `images/` | weather에서만 쓰는 이미지 |
| `data/` | weather에서만 쓰는 데이터 |
