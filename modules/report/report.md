# 1. 분석 리포트 (`report`)

결과 데이터 요약, 문제 분석, 리포트 다운로드

| 파일 | 내용 |
|---|---|
| `report_main.html` | 화면 (`<section id="report-section">` 하나) |
| `report_style.css` | 디자인 (class는 `report-`로 시작) |
| `report_script.js` | 화면 기능 (`Report` 객체, `Report.init()`) |
| `report_server.py` | 서버 기능 (주소는 `/report/...`) |
| `images/` | report에서만 쓰는 이미지 |
| `data/` | report에서만 쓰는 데이터 |
