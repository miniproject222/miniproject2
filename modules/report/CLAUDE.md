# report 모듈 AI 작업 안내

이 파일은 Claude Code가 `modules/report/`에서 작업할 때 자동으로 읽습니다.

## 프롬프트 기록 (필수)

- 작업을 시작하면 `modules/report/report_prompt.md`를 먼저 읽어 주세요.
- 작업이 끝날 때마다, 이번 대화에서 보고서에 쓸 만한 프롬프트가 있었으면 그 파일의 "AI에게: 기록 규칙"과 "기록 형식"대로 `## 기록` 맨 아래에 추가해 주세요.
- "안녕", "응", "맞아", "고마워", "다시 해 줘" 같은 짧은 말과 단순 요청은 기록하지 않습니다.
- 기록할 것이 없으면 추가하지 않아도 됩니다.
- 기록 파일에 쓰는 것은 이 모듈 폴더 안의 작업이므로 따로 허락을 받지 않아도 됩니다.
