## AI에게: 기록 규칙

**※ 2026-10-26 PM 결정: 자동 기록 중단.** 작업이 끝나도 자동으로 기록하지 않고, 사용자가 "프롬프트 기록해 줘"처럼 직접 요청할 때만 아래 규칙대로 기록해 주세요.

**기록하는 것**
- 결과가 잘 나와서 담당자가 받아들인 프롬프트
- 처음엔 실패했지만 프롬프트를 고쳐서 해결한 경우 (실패한 프롬프트와 고친 프롬프트 모두)
- AI가 틀린 정보를 지어내거나(환각), 시키지 않은 파일을 고치는 등 실수를 막은 프롬프트
- 앱 안에서 쓰는 AI 프롬프트(시스템 프롬프트 등)를 새로 만들거나 고친 경우

**기록하지 않는 것**
- "안녕", "응", "맞아", "고마워", "ㅇㅋ", "다시 해 줘", "계속" 같은 짧은 말
- 오타 수정, 파일 위치 묻기처럼 결과가 남지 않는 단순 요청
- 이미 기록한 것과 거의 같은 프롬프트

**쓰는 방법**
- 프롬프트는 담당자가 쓴 **원문 그대로** 넣습니다. 다듬거나 요약하지 않습니다.
- API 키, 비밀번호, Supabase 주소, 개인정보는 `***`로 가립니다.
- 새 기록은 `## 기록` 맨 아래에 번호를 이어서(P-01, P-02 …) 추가합니다. 이전 기록은 고치거나 지우지 않습니다.
- 기록을 추가했다면 `## 요약`의 표도 한 줄 갱신합니다.
- 앱 안 AI 프롬프트를 고쳤다면 `## 앱 안 AI 프롬프트 버전`에도 한 줄 추가합니다.
- 기록했다면 작업 끝에 "프롬프트 기록에 P-00을 추가했습니다"라고 알려 줍니다.

### P-01 · 2026-10-23 · 레퍼런스 대시보드 그대로 홈 화면 만들기 (독일 육각형 지도 + 도시 기온)

- 분류: 디자인
- 문제 유형: 형식 깨짐

**잘 쓴 프롬프트 (원문)**
```text
(레퍼런스 대시보드 이미지 첨부) 일단 지구는 독일 땅을 보여주고 이 사진을 최대한 살리고 아니 무조건 같게 하고 독일의 중요지역 몇개의 기온을 보여주게 하게 해봐 난 home 담당이고 다른거 건들지마
```

**처음 시도와 문제**
- 처음 프롬프트: 위와 같음
- AI가 한 실수: 지도와 미니 차트를 인라인 `<svg>`로 넣었는데, `st.html`이 보안 정리 과정에서 `<svg>`를 지워 화면에 아무것도 안 보였음

**해결 전략**: 코드만 보고 끝내지 않고 앱을 실제로 띄워 스크린샷으로 레퍼런스와 비교했고, SVG를 data URI `<img>`로 바꿔 해결함. "home 담당, 다른 거 건들지 마"를 처음부터 말해서 공용 파일(`ui_theme.py`, `assets/`)은 읽기만 함
**결과**: `home_globe.py` 새로 만듦 (독일 경계 GeoJSON → 육각 격자 구, Open-Meteo로 7개 도시 현재 기온, 실패 시 샘플 기온), `home_page.py`와 `home_style.css`를 레퍼런스 3단 배치로 다시 작성
**다음에 쓸 팁**: 레퍼런스 이미지와 함께 "무조건 같게"와 "내 폴더만"을 같이 말하고, 결과는 스크린샷으로 비교해 달라고 요청하기

### P-02 · 2026-10-23 · 레퍼런스와 똑같이 다시 맞추기 + 우주에서 본 독일 위성 지구본

- 분류: 디자인
- 문제 유형: 지시 해석 오류 (요청보다 팀 규칙을 우선함)

**잘 쓴 프롬프트 (원문)**
```text
(현재 화면 스크린샷 + 레퍼런스 이미지 첨부) 이게 맞니난 두번째 사진대로 하라 했는데 그리고 첫번째 독일 지도를 벌집처럼 말고 우주에서 독일 땅보이는대로 해주렴
```

**처음 시도와 문제**
- 처음 프롬프트: P-01의 프롬프트 ("이 사진을 최대한 살리고 아니 무조건 같게")
- AI가 한 실수: 배치만 따라 하고, 색은 팀 팔레트로, 문구는 한국어 샘플로 바꿈. 지도도 육각형(벌집) 무늬로 만듦

**해결 전략**: 결과 화면과 레퍼런스를 나란히 보여 주며 "두번째 사진대로"라고 기준을 하나로 정함. 지도는 "우주에서 보이는 대로"처럼 원하는 모습을 구체적으로 말함
**결과**: NASA Blue Marble 위성 사진(퍼블릭 도메인)을 `images/home_europe_bluemarble_01.jpg`로 크롭해서, 독일 중심 구에 입히고 독일만 밝게, 국경선은 흰색으로 표시함. 색(HOME_COLORS), 영어 문구, 숫자를 레퍼런스와 같게 바꿈 (`home_globe.py`, `home_page.py`, `home_style.css`)
**다음에 쓸 팁**: "같게"를 원하면 비교용 스크린샷을 같이 주고 "색, 글자까지 그대로"처럼 범위를 분명히 말하기

### P-03 · 2026-10-24 · dev 병합 후 사라진 홈 변경 복구

- 분류: 버그 수정
- 문제 유형: 기존 코드 삭제

**잘 쓴 프롬프트 (원문)**
```text
jh이 한거 땡겨온건가 내가 한거 지우고
```

**처음 시도와 문제**
- 처음 프롬프트: 위와 같음
- AI가 한 실수: 없음. dev를 DH 브랜치에 병합할 때 home_page.py, home_data.py, home.md가 충돌했고, dev 쪽 버전으로 해결돼 "홈 수정" 커밋 내용이 사라짐. 남아 있던 새 home_globe.py와 맞지 않아 홈이 열자마자 오류가 나는 상태였음. 복구 후 커밋 전에 변경 사항이 한 번 더 버려져 다시 복구함

**해결 전략**: AI가 git log·reflog·diff(읽기 전용)로 어느 커밋이 어떤 파일을 덮었는지 확인. 내 커밋(86c4e39)에서 3개 파일을 복구하고, 팀원 커밋(solution 모듈 삭제 → media로 합침, 날씨 탭 ④)의 의도만 홈에 다시 반영함
**결과**: home_page.py, home_data.py, home.md 복구 + HOME_STEPS에서 solution 제거. Python 3.11 환경에서 실행해 화면·탭 이동 확인
**다음에 쓸 팁**: 병합 충돌이 나면 "전부 상대 쪽으로"를 누르지 말고 파일별로 비교하기. 복구한 뒤에는 바로 커밋해서 다시 사라지지 않게 하기

### P-04 · 2026-10-25 · 지금 할 일: ① 핵심 요약 + ④ 날씨 알림 (report 담당 대리 작업)

- 분류: 기능
- 문제 유형: ④가 store에 저장하지 않아 홈 날씨 알림이 항상 샘플('경쟁사 A 아마존 품절')

**잘 쓴 프롬프트 (원문)**
```text
1. 2번탭에 스크롤이 다시 생겼어 안생기도록 확인해
2. 홈화면에 지금 할 일을 하나 더 만들고 위에는 1번 탭의 중요사항을 간략보고 아래는 날씨에서 가지고 오는 데이터
3. 4번 탭은 위에 공백을 다른 페이지와 맞추고, 글씨색을 1번 탭기준으로 맞춰, 폭염 시나리오를 자동 활성화로 변경해줘
4. 6번째 사진 아마존으로 변경해줘
(확인 답변) 오늘 홈·④도 수정 권한 있음 / 메타 대신 아마존 예산 차트
```

**처음 시도와 문제**: 홈 할 일은 report·weather store에서 만드는데, ① 핵심 문제(key_problems)는 읽지 않았고 ④는 store에 아무것도 저장하지 않아 HOME_DEMO 샘플 알림만 보였음. 홈이 ④보다 먼저 그려져 첫 화면에는 ④ 값이 아직 없음
**해결 전략**: ① key_problems가 있으면 맨 위에 '① 1순위 · 내부/외부 | 제목' + 근거 요약·2순위 할 일(문제 분석 보기). ④가 store("weather")에 배수·근거·알림을 저장하고 홈은 그 알림을 아래에 표시. 날씨 샘플(HOME_DEMO weather)은 더 이상 쓰지 않음(첫 화면은 홈 기온 규칙으로 배수)
**결과**: home_data.py. 실제 브라우저: 지금 할 일 2개 (① 1순위 UWG / 4일 연속 30°C 이상 예보 남부 (폭염 시나리오 샘플)), 광고 빈도 x1.8, 오류 0개

### P-05 · 2026-10-25 · 처음 열 때 ④ 날씨 할 일이 안 보임 → ① 자리 안내 + ④ 첫 저장 뒤 다시 그림 (report 담당 대리 작업)

- 분류: 기능
- 문제 유형: 그리는 순서 (홈이 ④보다 먼저 그려져 첫 화면에 ④ store가 아직 비어 있음)

**잘 쓴 프롬프트 (원문)**
```text
1. 우측 화면을 조금 더 줄여도 될거같아
2. 이 사진에 있는 내용 하단에 4번 탭에서 나오는 데이터가 사라졌어 확인해봐
3. 메타에 대한 내용을 아마존으로 변경해
(확인 답변) 메타를 빼고 아마존만
```

**처음 시도와 문제**: 앱을 처음 열면 홈이 먼저 그려지고 ④가 그 뒤에 store("weather")를 저장해서, 다른 탭을 눌렀다 와야 날씨 할 일이 보였음. ①을 저장하기 전에는 ① 자리도 비어 있었음
**해결 전략**: ① 리포트가 없으면 맨 위에 '① 1순위 · 문제 분석 결과가 아직 없어요' 안내 할 일(문제 분석 보기). ④는 세션에서 처음 저장할 때 한 번 `st.rerun()`해서 홈이 바로 ④ 값을 읽게 함 (weather_page.py)
**결과**: home_data.py, weather_page.py. 실제 브라우저: 첫 화면 '① … 아직 없어요' + ④ 아마존 폭염일 할 일, ① 다음으로 뒤 ① 1순위 요약 + ④ 할 일, 오류 0개
