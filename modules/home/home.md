# 홈 (`home`)

관제실: "오늘 뭘 먼저 해야 하는지" 알려 주는 출발점 (보여주기 → 알려주기 → 연결하기)

| 파일 | 내용 |
|---|---|
| `home_page.py` | 화면 (`home_render()`), 팝업, 탭 이동 버튼 |
| `home_data.py` | 다른 탭 데이터 읽기 (`store_get`), 샘플 데이터, 폭염경보 판단, "지금 할 일" 규칙 |
| `home_globe.py` | 가운데 위성 지구본 + 주요 도시 실시간 기온·7일 예보 (Open-Meteo) |
| `home_style.css` | 디자인 (class는 `home-`로 시작) |
| `images/home_europe_bluemarble_01.jpg` | 지구본용 위성 사진 (NASA Blue Marble, 퍼블릭 도메인) |
| `data/` | home에서만 쓰는 데이터 |

## 화면 구성 (읽는 순서대로)

| 자리 | 내용 | 데이터 |
|---|---|---|
| 왼쪽 위 | "독일 시장 한눈에 보기" + 오늘 날짜 | - |
| 왼쪽: 큰 숫자 | **광고 빈도 추천 x1.3** (+ 근거, 조정 → ④) | `weather` (없으면 홈 기온 규칙) |
| 왼쪽: 아이콘 숫자 2개 | 지금 최고 기온 도시 / 더위 경보(30°C↑) 도시 수 | Open-Meteo |
| 왼쪽: 작은 카드 2개 | 전날 매출(없으면 내일 평균 최고 기온) / A/B 테스트 클릭률 막대(없으면 이번 주 가장 더운 도시 3곳 막대) | `report`, Open-Meteo |
| 왼쪽: 긴 카드 | **7일 최고 기온 예보** (도시 × 요일 칸, 진할수록 더움, 30°C↑ 빨간 칸) | Open-Meteo 7일 예보 (`daily`) |
| 오른쪽: 지구본 | 하얀 입체 지구본(위성 사진의 지형 굴곡만 사용), 독일만 연보라 + 보라 국경선, 중심에서 6도. 도시 핀(기온 색 칸 + 이름 말풍선, 기온이 높을수록 큰 원), 경보 배지, 아래 기온 색 안내(20°↓ 파랑 · 20~29° 주황 · 30°↑ 빨강) | Open-Meteo (실시간) |
| 오른쪽 아래: **지금 할 일 아이콘** | 할 일 개수 배지 + "지금 할 일 확인하기" 말풍선과 꺾인 화살표. 누르면 팝업: 큰 카드 ①·④(왜? + 바로가기 + 다음 단계), 나머지 한 줄씩. 페이지를 처음 열면 한 번 자동으로 열리고, 열림/닫힘은 다시 그려져도 유지 | `report`, 7일 예보 폭염, `weather` 알림 |

- 2026-10-26 정리: "오늘의 관제실" 제목, 위 "가장 먼저" 줄, 아래 "마케팅 사이클" 줄, 처음 접속 팝업 2개는 지금 할 일과 내용이 겹쳐 삭제했습니다.
  같은 날 레퍼런스('General statistics' 대시보드) 배치로 바꾸면서 오른쪽 "지금 상황" 카드 3개는 왼쪽 큰 숫자·카드로 옮겼습니다.
- 모든 버튼(할 일, 광고 빈도, 카드의 "자세히 →", 아이콘 숫자 2개)을 누르면 해당 탭으로 바로 이동합니다.
- 할 일 팝업은 **아이콘에 마우스를 올리면 열리고** 벗어나면 0.3초 뒤 닫힙니다(아이콘 → 팝업으로 옮겨도 유지). 터치 화면을 위해 눌러도 열립니다.
  ×, 탭 이동 버튼, 팝업 바깥 클릭, Esc 키로도 닫힙니다.
- 지구본은 오른쪽 칸보다 크게(680) 그리고 왼쪽으로 90 당겨 화면 가운데 쪽에 둡니다 (바깥 고리는 왼쪽 카드 뒤로, 위아래 옅은 빛 번짐은 겹쳐서 잘리지 않게).
- 전날 매출 카드 아래에 7일 매출 꺾은선(데이터가 없으면 7일 평균 최고 기온 꺾은선), 예보 표의 '오늘' 열은 보라 굵은 글씨.
- 다른 탭이 아직 구현 전이면 샘플 데이터로 채우고 "샘플" 표시가 붙습니다.
- 시연용: 주소 끝에 `?scenario=heat`를 붙이면 실제 기온 대신 여름 폭염 시나리오로 보여 줍니다.

## 홈이 읽는 데이터 모양 (각 탭 담당자에게 요청)

```python
store_set("report", {
    "yesterday_sales": 1284.0,        # 전날 매출 (€)
    "sales_delta": -0.18,             # 전일 대비 증감 (비율, -0.18 = 18% 하락)
    "sales_7d": [980, 1020, 1100, 1500, 1620, 1560, 1284],   # 최근 7일 매출 (오래된 날 → 어제)
    "problems": [{"title": "장바구니 이탈 증가", "type": "내부"}],   # type: 내부 / 외부
})
store_set("weather", {
    "ad_multiplier": 1.8,             # 광고 빈도 배수
    "reason": "폭염 + 경쟁사 품절",
    "alerts": [{"level": "high", "text": "경쟁사 품절 감지"}],     # level: high(팝업) / info
})
# hypothesis, media: 내용은 자유. 값이 저장되어 있으면 "완료"로 표시 (media = 광고 소재 + 솔루션)
```

- 위젯 `key`, `st.session_state` 키는 `home-`로 시작합니다. (예: `home-alerts-shown`)
- Supabase 표 이름은 `home_`로 시작합니다. (예: `home_result`)
