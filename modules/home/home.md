# 홈 (`home`)

관제실: "오늘 뭘 먼저 해야 하는지" 알려 주는 출발점 (보여주기 → 알려주기 → 연결하기)

| 파일 | 내용 |
|---|---|
| `home_page.py` | 화면 (`home_render()`), 지금 할 일 아이콘·팝업, 진행 카드, 탭 이동 |
| `home_data.py` | 다른 탭 데이터 읽기 (`store_get`), 샘플 데이터, 폭염경보 판단, "지금 할 일" 규칙 |
| `home_globe.py` | 오른쪽 독일 중심 지구본(회색 유럽 지도) + 주요 도시 실시간 기온·7일 예보 (Open-Meteo) |
| `home_style.css` | 디자인 (class는 `home-`로 시작) |
| `data/home_europe_countries_ne50m.geojson` | 지구본용 국경 (Natural Earth 1:50m Admin 0 Countries v5.1.2, 퍼블릭 도메인, 유럽 중부만 잘라 냄) |
| `images/home_europe_bluemarble_01.jpg` | (지금은 안 씀) 예전 위성 지구본 사진 (NASA Blue Marble, 퍼블릭 도메인) |
| `data/` | home에서만 쓰는 데이터 |

## 화면 구성 (2026-10-26 기준, 읽는 순서대로)

| 자리 | 내용 | 데이터 |
|---|---|---|
| 왼쪽 위 | "독일 시장 한눈에 보기" | - |
| 왼쪽: 큰 숫자 자리 | **독일 시간 · 베를린** (라벨 옆 작은 시차 '-8h', 마우스를 올리면 '한국보다 8시간 느려요') 큰 시계(초 단위로 바뀜) + 아래 줄: 날짜 · **연락 가능 표시**(독일 오전 9시~오후 5시 '🟢 연락 가능 시간', 그 밖 '🔴 근무 외 시간', `HOME_WORK_START/END`, 1초마다 갱신) (예전 '광고 빈도 추천' 자리) | 브라우저 시계 (Europe/Berlin) |

- 2026-10-26 정리 (요청 순서대로)
  - "오늘의 관제실" 제목, 위 "가장 먼저" 줄, 아래 "마케팅 사이클" 줄, 처음 접속 팝업은 지금 할 일과 겹쳐 삭제.
  - 날씨만 보이던 카드 3개(내일 기온·더운 도시·7일 예보 달력)는 "들어오자마자 필요한 정보"(② 가설 / ③ A/B / 경쟁사 가격)로 교체.
  - 오른쪽 아래 할 일 아이콘(꺾인 화살표)은 왼쪽 할 일 아이콘 줄로 옮겨 삭제.
  - 카드마다 있던 "자세히 →"·"샘플" 배지는 지움: 카드 전체를 누르면 이동(마우스를 올리면 → 표시), 샘플 여부는 지구본 아래 한 줄로.
  - 색은 보라 한 계열 + 경고(주황·빨강)만.
  - 큰 숫자 '광고 빈도 추천 x1.3'은 요청으로 삭제 (광고 빈도는 할 일 ④ 카드에서 봄).
- 진행 카드는 **실제 저장값만** 보여 줍니다 (다른 탭이 저장 전이라 샘플로 채운 값은 카드에 안 씀).
- 지구본은 폭 690(기준 화면 기준)으로 왼쪽 카드와 오른쪽 패널 사이에 두고(바깥 고리는 카드 뒤로 살짝), 넓은 화면에서는 `left: 50% - 275`로 가운데 쪽으로 같이 이동합니다. 핀 색 안내·출처는 오른쪽 아래.
- 지역 비중은 ④가 store에 저장하지 않아 홈이 같은 규칙으로 계산합니다. ④는 권역마다 도시 3곳 평균, 홈은 대표 도시 1곳 기온을 써서 ④ 화면 숫자와 조금 다를 수 있습니다.
- 핀 인구 (원 크기): 베를린 3,700,577 · 함부르크 1,869,473 · 뮌헨 1,505,036 · 쾰른 1,025,523 (2025-12-31, 위키백과 'Liste der Großstädte in Deutschland'가 옮긴 주 통계청 추계값). 원 지름 = 96 × √(인구 ÷ 베를린 인구).
  ④ 담당자에게 요청: `store_set("weather", {..., "regions": [{"name": "남부", "share": 32.0, "week": 1600}]})`를 추가하면 홈이 그 값을 그대로 쓰도록 바꿀 수 있습니다.
- 시연용: 주소 끝에 `?scenario=heat`를 붙이면 실제 기온 대신 여름 폭염 시나리오로 보여 줍니다.

## 홈이 읽는 데이터 모양 (각 탭 담당자에게 요청)

```python
store_set("report", {
    "problems": [...], "key_problems": [...],          # 지금 할 일 ① 1순위
    "competitor_signals": [{"brand", "price", "in_stock", "price_change_90d", "fetched_at"}],   # 경쟁사 가격 카드
    "competitor_profiles": [{"brand", "rating", "reviews", ...}], "seori_profile": {"amazon_price", "rating", "reviews"},
    "yesterday_sales": 1284.0, "sales_delta": -0.18, "ab_test": {...},   # (GA4 연결 후) 매출·A/B 할 일
})
store_set("hypothesis", {"selected": {"if", "because", "then", "problem": {"title"}}, "text": "..."})   # ② 카드
store_set("media", {"handoff": {"plan": {"variable", "a", "b", "kpi_now", "kpi_goal"}}})            # ③ 카드
store_set("weather", {
    "ad_multiplier": 1.8,             # 광고 빈도 배수 (큰 숫자)
    "reason": "폭염 + 경쟁사 품절",
    "alerts": [{"level": "high", "text": "경쟁사 품절 감지"}],     # level: high / info (지금 할 일)
})
```

- 위젯 `key`, `st.session_state` 키는 `home-`로 시작합니다. (예: `home-alerts-shown`)
- Supabase 표 이름은 `home_`로 시작합니다. (예: `home_result`)
