# 홈 (`home`)

관제실: "오늘 뭘 먼저 해야 하는지" 알려 주는 출발점 (보여주기 → 알려주기 → 연결하기)

| 파일 | 내용 |
|---|---|
| `home_page.py` | 화면 (`home_render()`), 팝업, 탭 이동 버튼 |
| `home_data.py` | 다른 탭 데이터 읽기 (`store_get`), 샘플 데이터, 폭염경보 판단, "지금 할 일" 규칙 |
| `home_globe.py` | 가운데 위성 지구본 + 주요 도시 실시간 기온·7일 예보 (Open-Meteo) |
| `home_style.css` | 디자인 (class는 `home-`로 시작) |
| `images/home_europe_bluemarble_01.jpg` | 지구본용 위성 사진 (NASA Blue Marble, 퍼블릭 도메인) |
| `data/` | home에서만 쓰는 데이터 |

## 화면 구성 (읽는 순서대로)

| 자리 | 내용 | 데이터 |
|---|---|---|
| 위: 한 줄 요약 | "가장 먼저 ○○ → [바로가기]" | 지금 할 일 1번 |
| 왼쪽: **지금 할 일** | 급한 순(지금 → 오늘 → 이번 주). 1번은 크게(왜? + 바로가기 + 다음 단계), 2번부터 한 줄씩 | `report` A/B·매출, 7일 예보 폭염, `weather` 알림 |
| 가운데: 지구본 | 독일 주요 도시 기온, 폭염경보(33°C↑)·더위 주의(30°C↑) 배지 | Open-Meteo (실시간) |
| 오른쪽: 지금 상황 | 광고 성과(매출·클릭률·전환율·광고비·A/B), 날씨 요약, 광고 빈도 추천 | `report`, 기온, `weather` |
| 아래: 마케팅 사이클 | ① → ② → ③ → 광고 집행 → 다시 ①, 완료 ✓ / 지금 여기 / 대기 + ④ 계속 감시 중 | 각 탭 `store` |
| 팝업 | 접속 후 처음 한 번, 급한 할 일 2개 | 지금 할 일 |

- 모든 버튼(팝업, 할 일, 사이클 단계, 광고 빈도)을 누르면 해당 탭으로 바로 이동합니다.
- 다른 탭이 아직 구현 전이면 샘플 데이터로 채우고 "샘플" 표시가 붙습니다.
- 시연용: 주소 끝에 `?scenario=heat`를 붙이면 실제 기온 대신 여름 폭염 시나리오로 보여 줍니다.

## 홈이 읽는 데이터 모양 (각 탭 담당자에게 요청)

```python
store_set("report", {
    "yesterday_sales": 1284.0,        # 전날 매출 (€)
    "sales_delta": -0.18,             # 전일 대비 증감 (비율, -0.18 = 18% 하락)
    "sales_7d": [980, 1020, 1100, 1500, 1620, 1560, 1284],   # 최근 7일 매출 (오래된 날 → 어제)
    "problems": [{"title": "장바구니 이탈 증가", "type": "내부"}],   # type: 내부 / 외부
})
store_set("weather", {
    "ad_multiplier": 1.8,             # 광고 빈도 배수
    "reason": "폭염 + 경쟁사 품절",
    "alerts": [{"level": "high", "text": "경쟁사 품절 감지"}],     # level: high(팝업) / info
})
# hypothesis, media, solution: 내용은 자유. 값이 저장되어 있으면 "완료"로 표시
```

- 위젯 `key`, `st.session_state` 키는 `home-`로 시작합니다. (예: `home-alerts-shown`)
- Supabase 표 이름은 `home_`로 시작합니다. (예: `home_result`)
