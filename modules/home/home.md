# 홈 (`home`)

날씨, 달력, 전날 매출과 이슈 알림

| 파일 | 내용 |
|---|---|
| `home_main.html` | 화면 (`<section id="home-section">` 하나) |
| `home_style.css` | 디자인 (class는 `home-`로 시작) |
| `home_script.js` | 화면 기능 (`Home` 객체, `Home.init()`) |
| `home_server.py` | 서버 기능 (주소는 `/home/...`) |
| `images/` | home에서만 쓰는 이미지 |
| `data/` | home에서만 쓰는 데이터 |
